# Part 1 — Project Intent

## Project Title

AI-Assisted House Price Prediction

## Objective

The goal of this project is to build an end-to-end data science workflow
that predicts residential house prices using the Kaggle House Prices dataset.

An AI coding assistant will be used throughout the data science lifecycle
for planning, coding, debugging, analysis, and documentation.

However, AI-generated outputs will be reviewed, validated, and explained
in my own words.

## Business Problem

House prices depend on many factors such as property quality, living area,
age, garage capacity, neighborhood, and other characteristics.

The objective is to determine whether these available property features
can be used to predict a home's sale price accurately.

## Dataset

Kaggle House Prices: Advanced Regression Techniques

Target variable:

- `SalePrice`

The dataset contains numerical and categorical features describing
residential properties.

## Main Question

Can we build a machine learning model that predicts `SalePrice`
from the available property characteristics with reasonable accuracy?

## Data Science Approach

The project will follow a structured workflow inspired by CRISP-DM:

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Interpretation and Communication

## Role of AI

ChatGPT and/or an agentic coding assistant may help with:

- planning the analysis
- generating and reviewing Python code
- suggesting preprocessing approaches
- suggesting machine learning models
- debugging
- interpreting model results
- organizing project documentation

AI-generated results will not be accepted blindly.
The results will be checked and paraphrased based on my own understanding.

## Success Criteria

The project will be considered successful if:

- the dataset is explored and understood
- missing and categorical data are handled appropriately
- multiple regression approaches are evaluated
- model performance is measured using appropriate metrics
- the final model is compared against a baseline
- important features and prediction errors are interpreted
- the entire workflow is reproducible
- the final results can be clearly explained in my own words
