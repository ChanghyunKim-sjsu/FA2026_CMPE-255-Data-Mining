# Anomaly Detection Experiment Plan

## Objective

Replicate and simplify the anomaly detection experiment from the professor's
data_science_examples repository.

## Workflow

1. Load and inspect the dataset
2. Examine feature distributions and data quality
3. Prepare numerical features
4. Standardize the features
5. Apply Isolation Forest
6. Calculate anomaly scores and labels
7. Analyze detected anomalies
8. Visualize normal and anomalous observations using PCA
9. Save results and figures
10. Document conclusions in the main Assignment 1 README
