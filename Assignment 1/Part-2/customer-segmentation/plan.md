# Customer Segmentation Experiment Plan

## Objective

Replicate and simplify a customer segmentation workflow using K-Means
clustering.

## Workflow

1. Load and inspect the dataset
2. Select clustering features
3. Standardize numerical features
4. Evaluate multiple values of k
5. Use elbow and silhouette analysis
6. Train the final K-Means model
7. Profile and interpret customer segments
8. Visualize clusters using PCA
9. Save results and figures
